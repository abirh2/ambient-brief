# Specifications

Store version-controlled feature specifications as `<feature-id>.md` using stable kebab-case IDs. For initiatives with independent capabilities, keep the reviewed capability map here and link each module spec by ID.

Follow the [development lifecycle and spec content requirements](../docs/development-workflow.md). Record draft/approval status, review history, measurable acceptance criteria, and material revisions before implementation. Link each spec to its plan in `../plans/`.

No Living World feature specification has been authored or approved by this workflow setup. The confirmed direction is recorded in [AGENTS.md](../AGENTS.md); detailed requirements and rendering choices remain future work.

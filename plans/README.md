# Implementation plans

Store each feature's plan, task checkboxes, milestone progress, and verification evidence in `<feature-id>.md`, matching and linking its reviewed spec in `../specs/`. Keep one plan/task record per feature rather than parallel `tasks/` files.

Follow the [development workflow](../docs/development-workflow.md). Update after meaningful milestones; distinguish planned work, completed work, failed checks, and unresolved conditions. No Living World implementation plan is created by this workflow setup.
